# Futebol RP

Core do mod de futebol para FiveM.

## Contribuindo

Para contribuir com este projeto, siga rigorosamente nossas convenções e fluxo de trabalho:

1. **Estratégia de Branches**: Leia nosso [Guia de Branches](.github/BRANCH_STRATEGY.md) para saber como nomear suas branches de fase ou correções. Lembre-se: **Nunca commite diretamente na main!**
2. **Padrão de Commits**: Suas mensagens de commit devem seguir estritamente o [COMMIT_CONVENTION.md](.github/COMMIT_CONVENTION.md).
3. **Pull Requests**: Todo o código novo precisa entrar via PR utilizando nosso [Pull Request Template](.github/pull_request_template.md). Certifique-se de detalhar o que foi modificado e as orientações para o teste.
